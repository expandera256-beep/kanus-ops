# 4. TAM İSTEM-BAŞI GPU SİSTEMİ

Kanus.org'un temel maliyet modeli istem-başı çalışan hesaplama altyapısıdır.

Hedef işleyiş:

Kullanıcı isteği
→ Kimlik doğrulama
→ Kredi kontrolü
→ İstek kuyruğu
→ GPU açılışı
→ DeepSeek yüklenmesi
→ Model hazır
→ Görevin çalıştırılması
→ Sonucun gönderilmesi
→ Kredi kesinleştirme
→ Etkinliksizlik kontrolü
→ GPU kapanışı

### Zorunlu gereksinimler

1. GPU boşken gereksiz yere açık kalmasın.
2. İstem geldiğinde otomatik açılsın.
3. Aynı anda gelen istekler tek GPU açılışını paylaşsın.
4. Model hazır olana kadar kullanıcı güvenli biçimde beklesin.
5. Aktif görev varken GPU kapanmasın.
6. Kuyrukta iş varken kapanma gerçekleşmesin.
7. Etkinliksizlik süresi yapılandırılabilir olsun.
8. Varsayılan boşta kalma süresi 10 dakika olsun.
9. GPU açılışında 10 dakikaya kadar bekleme desteklensin.
10. Hatalı açılışlarda kontrollü yeniden deneme yapılsın.
11. Watchdog sistemi gerçek kaynak durumunu takip etsin.
12. Cloud IAM yetkileri en az yetki ilkesiyle sınırlandırılsın.
13. Eski uyandırma sistemi güvenli geçişten sonra devreden çıkarılsın.
14. GPU maliyetleri kaydedilsin.
15. Sağlık kontrolleri GPU'yu açmasın.

### Mevcut kaynakları denetle

- `ds-a100`
- `instance-20261030-232245`
- `usta-wake`
- `usta-l4`
- `us-commerce`
- `us-watchdog`
- `us-idle-watchdog`

Bu kaynakların önceki durumlarını değil, erişilebiliyorsa güncel gerçek durumlarını esas al.

İstem-başı çalışma koşulunun gerçekten sağlandığını açılış, kullanım ve kapanış testleriyle doğrula.
