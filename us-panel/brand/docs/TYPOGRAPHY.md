# Tipografi

Font dosyası indirilmez; sistem / açık lisanslı yığınlar.

## UI (Türkçe öncelikli)

```
"Segoe UI", system-ui, -apple-system, "Helvetica Neue", Arial, sans-serif
```

- Başlık: 700–800, sıkı letter-spacing (−0.02…−0.04em)
- Gövde: 400–500, satır yüksekliği ~1.5

## Terminal / kod (§7 monospace)

```
ui-monospace, "Cascadia Mono", "Cascadia Code", Consolas, "Courier New", monospace
```

Linux yedek: `"DejaVu Sans Mono", "Liberation Mono", monospace`

## Wordmark

- **KANUS:** Segoe UI / system-ui, Bold
- **US PANEL:** monospace, geniş letter-spacing (~0.18em), `blue_neon`

## Lisans notu

Segoe UI, Cascadia, system-ui — işletim sistemiyle gelen fontlar; projeye font dosyası gömülmez. Web’de benzer açık alternatif önerisi (uygulama ayrı onay): **Inter** (UI), **JetBrains Mono** / **IBM Plex Mono** (terminal) — henüz indirilmedi / gömülmedi.
